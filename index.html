Modèle

Serveur distant (optionnel)

Utilise un modèle hébergé sur votre propre serveur Ollama (par exemple derrière Caddy). Vos messages sont alors envoyés à ce serveur, en HTTPS.

Le mot de passe est défini sur le serveur avec la commande « ll-auth passwd ». Il n'est pas enregistré sur cet appareil : seule une session révocable l'est.

Un contexte plus grand consomme plus de mémoire sur le serveur : avec 4 Go de RAM, restez à 4096 pour un modèle de 4 milliards de paramètres. Si le serveur manque de mémoire, il le signale.

Génération

Un contexte plus grand consomme plus de mémoire. Le modèle est rechargé au prochain message si le contexte change. L'historique est tronqué automatiquement.

Prompt système personnalisé

Utilisé quand le rôle « Personnalisé » est choisi (menu au-dessus de la zone de saisie).
